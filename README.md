**Tech:** Computer Vision, Object Detection, Python, Flutter, Telecommunications

**Tech:** Python, Raspberry Pi, OpenCV, YuNet, ArcFace, SVC, Supabase, Firebase Cloud Messaging, Docker, Flutter

An intelligent complaint-analysis platform that classifies financial complaints and supports customer-service workflows.

**Results:**

- Product-category classification accuracy: **81.2%**
- Issue-category classification accuracy: **66.2%**

**Tech:** Python, NLP, Scikit-learn, TF-IDF, Logistic Regression, Pandas, Streamlit

### 💊 PHARMAWORLD Pharmacy Management Database

A structured SQL database system designed for a veterinary pharmacy.

The system models business operations including employees, departments, clients, products, inventory, transactions, employee leave, salaries, and financial analytics.

**Key Features:**

- Normalized database schema with more than 10 related tables
- Primary keys, foreign keys, checks, defaults, and integrity constraints
- Views for salary calculations, employee information, and dynamic offers
- Queries for monthly profit, active clients, best-selling products, and inventory analysis
- Insert, update, and delete operations for major system entities
- Automatic ID generation for new entries

**Tech:** SQL Server, Database Design, Views, Joins, Constraints, DML, Analytics Queries
